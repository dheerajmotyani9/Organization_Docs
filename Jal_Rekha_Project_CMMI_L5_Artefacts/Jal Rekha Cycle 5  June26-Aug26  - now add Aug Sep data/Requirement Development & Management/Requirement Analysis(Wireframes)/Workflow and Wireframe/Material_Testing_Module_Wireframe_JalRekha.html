Business Rules (BR)

8 rules
IDRuleDescriptionApplies to
BR‑MT‑01Image mandatory — Cycle 1Geo‑tagged photo upload is mandatory before Contractor/FE can submit in Cycle 1 (loop_iteration = 1). Submission is blocked without at least one photo.Screens 1, 3
BR‑MT‑02Image optional — Cycle 2Photo upload is optional for the re‑inspection cycle (loop_iteration = 2). Submission is not blocked by missing photos.Screen 8, Cycle 2 flow
BR‑MT‑03Same RFI ID retainedCycle 2 re‑inspection reuses the original RFI ID — no new RFI is raised for a re‑inspection cycle.Cycle 2 flow
BR‑MT‑04Loop capped at 2 — no repeatloop_iteration is capped at 2 for Material Testing. The rejection branch cannot be re‑triggered a second time; the workflow engine force‑closes the RFI after the Cycle‑2 GM PIU decision.Screens 9, 10, GM Final node
BR‑MT‑05Rejection remark mandatoryGM PIU must enter a remark whenever rejecting an inspection result, in both Cycle 1 and Cycle 2.Screens 4, GM Reject node
BR‑MT‑06FE change visibilityA newly assigned FE (replacing one who left the project) must be able to view Cycle‑1 inspection data, GM's rejection remark and prior photos as read‑only reference.Screen 6, FE‑change scenario
BR‑MT‑07Terminal final decisionGM PIU's decision after Cycle 2 is terminal: Accept closes the RFI; Reject closes the RFI as Rejected‑Escalated for offline resolution. Neither outcome re‑opens the loop.Screen 9, GM Final node
BR‑MT‑08No new RFI for corrective actionContractor's corrective‑action confirmation is logged against the existing RFI and does not require raising a fresh request.Screen 5
