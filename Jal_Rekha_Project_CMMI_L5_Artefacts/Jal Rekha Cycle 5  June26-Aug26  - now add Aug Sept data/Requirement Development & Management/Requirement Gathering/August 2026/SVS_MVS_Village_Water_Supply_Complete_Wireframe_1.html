Business Rules (BR)

8 rules
IDRuleDescriptionApplies to
BR‑SVS‑01Infra status editable by Contractor onlyThe "Infra / Civil Work Completed" field can only be set by the Contractor. It becomes read‑only for all downstream roles (Gram Sachiv, CEO Block) once pushed forward.Contractor screen
BR‑SVS‑02Gram Sachiv fields locked until infra completeSource of Water, Cost Incurred and Document Upload remain disabled for a village row until "Infra Work Completed" = Yes. ⚠ Assumption — confirm this restriction is required.Gram Sachiv screen
BR‑SVS‑03Cost document must be PDFThe cost‑expenditure supporting document uploaded by Gram Sachiv is restricted to PDF format only.Gram Sachiv screen
BR‑SVS‑04CEO action requires complete record ⚠ CONFLICTAssumption: CEO Block's Accept/Reject button should only enable once Source of Water, Cost and Document are all filled. ⚠ Not explicit in the handwritten sketch — sketch shows the table simply "shown" to CEO with Accept/Reject added, no stated gating condition. Needs confirmation.CEO Block screen
BR‑SVS‑05Reject routing ⚠ UNCONFIRMEDThe 14‑Aug‑2026 sketch shows an Accept/Reject box at CEO Block level but does not draw where a Reject goes next. Modelled here as looping back to Gram Sachiv for correction and resubmission — could equally return to Contractor if the rejection concerns the infra work itself. Requires stakeholder sign‑off.CEO Block, decision node
BR‑SVS‑06Reuses existing Scheme/Village Master formatThe Contractor table (Scheme, District, Block, GP, Village, Contractor) mirrors the existing District‑GM Scheme/Village Master screen exactly — no new master table is introduced, only the "Infra Work Completed" field is added.Contractor screen
BR‑SVS‑07Single record carried across all 3 stagesEach village row keeps the same record ID as it moves from Contractor → Gram Sachiv → CEO Block; no new entry is created at each handoff, fields simply accumulate.All 3 role screens
BR‑SVS‑08MVS and SVS share one workflowMulti‑Village Scheme (MVS) and Single Village Scheme (SVS) records use the identical 3‑stage workflow and screen set, distinguished only by a Type flag (SVS/MVS) on each record.Contractor screen, filters
